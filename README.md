# 汎用テキストフォーマット検証ツール（C言語）

## 1. 開発の目的
このツールは大量のテキスト（小説の原稿）における、目視での判別不可能、または困難なヒューマンエラーを自動的に検知するコンソールアプリケーションです。

## 2. 基本的な機能
大量のテキストを1行ずつ読み込み、ルール違反を自動的に検知して行数とエラー内容を出力します。

* **インデント検証:** 行頭の全角スペース抜けの検知（会話文を除く）
* **連続記号検証:** 三点リーダー「…」やダッシュ記号「—」が奇数（二連続ではない）であれば検知
* **文字数カウント:** 文字数のカウント（改行、空白除く）
* **結果発表:** エラーの検知個数および発生箇所（行数）の出力

## 3. 動作環境
* **言語:** C言語
* **開発環境:** Visual Studio Code


## 4. 基本設計

入力ファイルを1バイトずつ読み込み、改行位置および過去の3バイトを監視して、文字数カウントと検知を同時に行う。

### 4.1 初期化
* `test.txt` を読み込みモード（`"r"`）でオープン。失敗時はエラーを出力し `return 1`（終了）。
* 文字数、特殊記号、字下げエラー等の各カウンタを `0` に初期化。
* 履歴保持用の変数 `prev1`, `prev2` を `0` に初期化。

### 4.2 メインループ（EOFまで1バイトずつ検知）
`fgetc()` で1バイト（変数 `c`）ずつ取得し、以下の判定を回す。

1. **行数・バイト数の制御**
   * `c == '\n'`（改行）の場合：行数（`current_line`）をインクリメント、行内バイト数（`line_byte_count`）を `0` にリセット。
   * `c != '\r'` の場合：行内バイト数（`line_byte_count`）をインクリメント。

2. **行頭の字下げ検証**
   * **【1段目】:** `line_byte_count == 1` のタイミングで判定。1バイト目が `0xE3` 以外（半角英数字や不正な全角文字など）であれば、その時点で字下げエラーとして検知し、警告を出力。
   * **【2段目】:** `line_byte_count == 3` に到達し、かつ1段目を通過（1バイト目が `0xE3`）した場合に判定。過去3バイト（`prev2`, `prev1`, `c`）が、全角スペース（`E3 80 80`）または始めカギ括弧（`E3 80 8C`）のいずれにも合致しない場合、字下げエラーとして検知し、警告を出力。

3. **総文字数カウント（UTF-8マルチバイト対応）**
   * `(c & 0xC0) != 0x80`（マルチバイトの後続バイトではない）の場合、文字の開始位置とみなして `char_count++`。

4. **特殊記号の検知**
   * 過去3バイトが `E2 80 A6`（…）に一致：`santen_count++`
   * 過去3バイトが `E2 80 94` または `E2 80 95`（—）：`dash_count++`
   * 過去6バイトが `E3 80 82 E3 80 82`または

5. **バッファ更新**
   * 次バイト判定のため、`prev5 = prev4;`、`prev4 = prev3;`、`prev3 = prev2;`、`prev2 = prev1;`、`prev1 = c;` として履歴をシフト。

### 4.3 終了処理・判定
* ファイルをクローズ（`fclose`）。
* 解析結果（文字数・記号数）を標準出力に表示。
* **最終ルール判定**
   * `santen_count % 2 != 0`（奇数）の場合：三点リーダーのエラー警告を出力。
   * `typo_error_count > 0` 「。。」や「、、」の場合：タイピングのエラー警告を出力。
   * `dash_count % 2 != 0`（奇数）の場合：ダッシュのエラー警告を出力。
   * `space_error_count > 0` の場合：字下げ忘れの総数を出力。
