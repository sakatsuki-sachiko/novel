# 汎用テキストフォーマット検証ツール（C言語）

## 1. 開発の目的
このツールは大量のテキスト（小説の原稿）における、目視での判別不可能、または困難なヒューマンエラーを自動的に検知するコンソールアプリケーションです。

## 2. 基本的な機能
大量のテキストを1行ずつ読み込み、ルール違反を自動的に検知して行数とエラー内容を出力します。

* **インデント検証:** 行頭の全角スペース抜けの検知（会話文を除く）
* **連続記号検証:** 三点リーダー「…」やダッシュ記号「—」が奇数（二連続ではない）であれば検知
* **カギ括弧の対応検証:** 会話文の始めカギ括弧「「」と閉じカギ括弧「」」のペアの不整合（閉じ忘れ、余分な括弧）を検知
* **タイポ（連続入力ミス）検知:** 句点「。。」や読点「、、」の意図しない連続入力を検知
* **文字数カウント:** 文字数のカウント（改行、空白除く）
* **結果発表:** エラーの検知個数および発生箇所（行数）の出力

## 3. 動作環境
* **言語:** C言語
* **開発環境:** Visual Studio Code

## 4. 基本設計

入力ファイルを1バイトずつ読み込み、改行位置および最大6バイト（現在バイト＋過去5バイト）を監視して、文字数カウントと書式検証を同時に行う。

### 4.1 初期化
* `test.txt` を読み込みモード（`"r"`）でオープン。失敗時はエラーを出力し `return 1`（異常終了）。
* 文字数、各種エラーをカウントする変数を `0` に初期化。
* カギ括弧の状態管理用変数（`is_bracket_open`, `bracket_opened_line`）を `0` に初期化。
* 履歴保持用の変数 `prev1` ～ `prev5` を `0` に初期化。

### 4.2 メインループ（EOFまで1バイトずつ走査）
`fgetc()` で1バイト（変数 `c`）ずつ取得し、以下の判定を回す。

1. **行数・バイト数の制御と行単位の検証**
   * `c == '\n'`（改行）の場合：
     * その行内でカウントした三点リーダーやダッシュが奇数であればエラーとして検知。
     * 次の行のために記号カウントを `0` にリセット。
     * 行数（`current_line`）をインクリメントし、行内バイト数（`line_byte_count`）を `0` にリセット。
   * `c != '\r'` の場合：行内バイト数（`line_byte_count`）をインクリメント。

2. **行頭の字下げ検証**
   * **【1段目】:** `line_byte_count == 1` のタイミングで判定。1バイト目が `0xE3` 以外（半角英数字や不正な全角文字など）であれば字下げエラー。
   * **【2段目】:** `line_byte_count == 3` に到達し、1バイト目が `0xE3` だった場合に判定。過去3バイトが、全角スペースまたは始めカギ括弧のいずれにも合致しない場合、字下げエラー。

3. **総文字数カウント（UTF-8マルチバイト対応）**
   * `(c & 0xC0) != 0x80`（マルチバイトの後続バイトではない）の場合、文字の開始位置とみなして `char_count++`。

4. **特殊記号・タイポ・状態の検知**
   * 過去3バイトが `E2 80 A6`（…）に一致：`santen_count++`
   * 過去3バイトが `E2 80 94` または `E2 80 95`（—）：`dash_count++`
   * 過去6バイトが `E3 80 82 E3 80 82`（。。）または `E3 80 81 E3 80 81`（、、）に一致：`typo_error_count++`
   * 過去3バイトが `E3 80 8C`（「）：
     * 既にフラグがON（開いている）ならエラー。OFFならフラグをONにし、発生行を `bracket_opened_line` に記憶。
   * 過去3バイトが `E3 80 8D`（」）：
     * フラグがOFF（開いていない）ならエラー。ONなら正常に閉じたとしてフラグをOFFにする。

5. **バッファ更新**
   * 次バイト判定のため、`prev5` から順に `prev1 = c` まで履歴をシフト。

### 4.3 終了処理・判定
* EOF到達時、改行されずに終わった最終行の三点リーダーおよびダッシュの奇数チェックを実施。
* ファイル末尾でカギ括弧のフラグがONのまま（閉じ忘れ）であればエラーとして検知。
* ファイルをクローズ（`fclose`）。
* 解析結果（文字数）を標準出力に表示。
* 各種エラーカウンタ（`santen_error_count`, `dash_error_count`, `bracket_error_count`, `typo_error_count`, `space_error_count`）が `0` より大きい場合、それぞれ警告文と検知数を出力。
